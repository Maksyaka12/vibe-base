# Security

Vibe Hub handles real funds: reward claims, staking, swaps and agent wallets on Base. If you find a vulnerability, please
tell us privately first and give us time to fix it.

## Report a vulnerability

Send a direct message to either contact:

- X: [@mksvibe](https://x.com/mksvibe)
- Telegram: [@mksvibe_base](https://t.me/mksvibe_base)

Please don't open a public issue or share details publicly until it is fixed. Include what you found, the steps to reproduce
it, and the contract address or page affected.

## Scope

- The app and its API at [vibehome.dog](https://vibehome.dog)
- The contracts in [contracts/](contracts/), with addresses in [contracts/README.md](contracts/README.md)
- The agent skills in [frontend/public/skills/](frontend/public/skills/) and [bankr-skill/](bankr-skill/)

Please test against your own wallets and never touch funds or data that aren't yours.
